Panduan Beli & Cara Dapatkan File

1. Pilih & Klik Beli

Pilih script yang kamu mau, klik Beli Sekarang. Muncul barcode DANA + nominal yang harus dibayar.

2. Bayar via DANA

Scan barcode di aplikasi DANA, masukkan nominal persis seperti yang tertera di website. Catat kode pesanan (format XR-...)

3. Verifikasi Pembayaran

Klik Saya Sudah Bayar, isi nama akun DANA, lalu kirim screenshot bukti dari aplikasi DANA (Riwayat -> detail transaksi) via WhatsApp admin beserta kode pesanan.

4. Pantau Status

Cek status di halaman Cek Status Pesanan memakai kode. Status berubah otomatis (LIVE).

5. Terima File

Saat status SELESAI, tombol Dapatkan File Saya muncul di halaman cek status. File juga dikirim admin lewat WhatsApp.
